ETOIの読み方

  1. 問いから入る「報われない」「否定された」。いまの自分に近い悩みから、一枚を選びます。
  2. 絵だけを見る説明を読む前に、まず何が見えるか。自分の目で感じる時間をつくります。
  3. 人生を知る画家が何にぶつかり、どう描き続けたか。所蔵館の資料で確かめた事実だけを書きます。
  4. 自分に重ねる答えは書きません。最後の一言を手がかりに、あなたの答えを考えてください。

週に一度、あなたに一枚を。
