STEP 3　背景を知る

見たことのないジャングル

ルソーは生涯フランスを出たことがありませんでした。メキシコに行ったという噂を、本人は否定しなかったといいます。ジャングルの手本は、パリ植物園の温室、動物園、剥製の展示、そして『野生の動物』などの図鑑の挿絵でした。この絵では、セージ、オリーブ、苔色、黄緑など、何層もの緑が壁のように重なり、草むらから2匹の獣が顔をのぞかせ、葉の陰には赤い鳥が隠れています。

笑われ続けた「税関吏」

1844年、フランス西部のラヴァルに生まれたルソーは、1871年からパリ市の入市税関（オクトロワ）で働きました。「ル・ドゥアニエ（税関吏）」というあだ名がつきましたが、実際にその役職だったことはありません。絵は独学で、1886年からアンデパンダン展にほぼ毎年出品しますが、批評家には長く笑われ続けました。1893年、49歳で職を辞めて絵に専念します。小さな絵をわずかな額で売り、ときには食料品の代わりに渡すほどの暮らしだったと伝えられます。

若い画家たちが開いた宴

晩年のルソーを認めたのは、若い画家たちでした。1908年、ピカソは自分のアトリエ「洗濯船」でルソーのための宴を開いています。ルソーは1910年9月2日、パリで亡くなりました。この絵は、画家ロベール・ドローネー、画商アンブロワーズ・ヴォラールらの手を経て、1928年に収集家チェスター・デイルが購入し、1963年にナショナル・ギャラリー・オブ・アートへ遺贈されました。2023年には、ルソーの《フラミンゴ》がニューヨークの競売で4,350万ドル（今の価値で約70億円）で落札され、作家の最高額を記録しています。
