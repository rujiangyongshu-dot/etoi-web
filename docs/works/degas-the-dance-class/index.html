STEP 3　背景を知る

試験の一場面

右で杖をつくのは、実在のバレエ教師ジュール・ペロー。中央でピンクの帯の少女がポーズを保ち、試験を受けています。奥には踊り子と母親たち、20人あまりが集まっています。ただしこの場面は想像で、舞台になったパリの旧オペラ座（ル・ペルティエ劇場）は、1873年10月の火事で焼け落ちていました。

注文主は人気歌手

この絵を注文したのは、オペラのバリトン歌手で収集家のジャン＝バティスト・フォール。鏡の横の貼り紙は、彼が歌ったロッシーニ《ギヨーム・テル》のもので、注文主への目くばせです。フォールは1876年の第2回印象派展にこの絵を貸し出しました。よく似た構図の一枚がパリのオルセー美術館にあり、こちらは1911年にカモンド伯爵の遺贈で入りました。メトロポリタン美術館の一枚はその後アメリカへ渡り、1986年にビンガム夫人の遺贈で美術館の所蔵となりました。

借金を抱えた年に

1874年、ドガの父が亡くなり、弟ルネが大きな借金を抱えていたことが分かります。同じ年、ドガは仲間と開いた第1回印象派展に作品を出しています。踊り子を描いた作品は約1,500点、全作品の半分以上にのぼります。1880年代の終わりには目が悪くなり始めましたが、それでも踊り子を描き続けました。
