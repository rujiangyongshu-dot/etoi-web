STEP 3　背景を知る

丸い画面の3人

「トンド」と呼ばれる円形の宗教画です。野原に腰を下ろした聖母マリアのひざで、幼子イエスが、幼い洗礼者ヨハネの差し出す細い十字架に手を伸ばしています。ラファエロが1508年にフィレンツェからローマへ移った後の作品で、もとは板に描かれていましたが、のちにカンヴァスへ移し替えられました。

公爵家から皇帝へ

18世紀にはスペインの名門アルバ公爵家が所有し、絵の名前はこの家に由来します。その後、人の手を渡り、1836年にロシア皇帝ニコライ1世のものとなって、サンクトペテルブルクのエルミタージュに収まりました。

ソ連が売った名画

ロシア革命の後、ソ連政府は外貨を必要とし、エルミタージュの名画をひそかに海外へ売りました。1931年、画商たちを通じてこの絵を買ったのが、アメリカの大富豪アンドルー・メロンです。メロンがエルミタージュから手に入れた21点は、1937年、彼が建設資金とともに国に贈ったワシントンのナショナル・ギャラリーの中核になりました。一国が手放した絵が、別の国の美術館の始まりになった——画商の目から見ても、これほど劇的な来歴はめったにありません。
